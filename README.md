# قدم‌به‌قدم — آکادمی ساخت سایت برای همه

یک وب‌اپ فارسی و راست‌چین که با زبان ساده یاد می‌دهد چطور یک ایده را به سایت تبدیل کنی.
مناسب برای کودکان ۸ سال به بالا (با همراهی بزرگ‌تر)، نوجوانان، بزرگسالان، معلمان و تازه‌واردان دیجیتال.

## قابلیت‌های نسخهٔ ۲

**صفحهٔ اصلی کامل و آموزشی**
- معرفی سه‌مرحله‌ای سایت (یاد بگیر، تمرین کن، بساز)
- راهنمای استفاده در چهار قدم، با دکمهٔ مستقیم برای هر قدم
- بخش «برای هر سنی» با راهنمای جداگانه برای پنج گروه سنی
- نقشهٔ کامل بخش‌های سایت
- مسیر شش‌قدمی یادگیری با درصد پیشرفت
- فهرست مهارت‌های نهایی، چهار قاعدهٔ استفادهٔ سالم
- یازده پرسش متداول و واژه‌نامهٔ ساده

**صفحهٔ راهنمای کامل**
- فهرست مطالب با ده بخش: شروع سریع، نقشهٔ سایت، روش انجام درس‌ها، کارگاه، پیشرفت، دسترس‌پذیری، حریم خصوصی، طرح درس ۳۰ دقیقه‌ای برای والدین و معلمان، رفع اشکال و واژه‌نامه

**مسیر یادگیری**
- شش درس با توضیح، «چرا مهم است»، چک‌لیست، مثال واقعی، نکته، راهنما و دستیار پرسش‌وپاسخ
- ذخیرهٔ خودکار پاسخ‌ها و امکان بازبینی و ویرایش هر درس
- قفل شدن قدم‌های بعدی تا تکمیل قدم قبل

**کارگاه ساخت**
- سه نمونهٔ آماده، شش رنگ اصلی، پیش‌نمایش زنده
- دریافت فایل HTML راست‌چین و واکنش‌گرا با رنگ انتخابی
- چک‌لیست قبل از انتشار

**پیشرفت و نمایه**
- آمار درس‌ها، درصد پیشرفت، تعداد واژه‌های نوشته‌شده
- چهار نشان (اولین قدم، نیمهٔ راه، مسیر کامل، نویسندهٔ دقیق)
- نمایش پاسخ‌ها، تنظیم اندازهٔ متن، پاک‌کردن پیشرفت

**دسترس‌پذیری و همه‌سنین**
- سه اندازهٔ متن (عادی، بزرگ، خیلی بزرگ) با دکمهٔ A+ و از صفحهٔ نمایه
- پیمایش کامل با صفحه‌کلید، حاشیهٔ فوکوس روشن، احترام به `prefers-reduced-motion`
- متن ساده، پرهیز از اصطلاح‌های فنی و هشدارهای حریم خصوصی برای کودکان
- PWA: manifest، آیکون و service worker؛ بدون هیچ درخواست خارجی (فونت از خود دستگاه)

## ساختار فایل‌ها

```
index.html     پوستهٔ برنامه، منو، پاورقی و متادیتا
styles.css     طراحی واکنش‌گرای کامل با متغیرهای رنگ
app.js         منطق، محتوا و رندر صفحه‌ها (بدون وابستگی)
manifest.json  تنظیمات PWA
sw.js          کش آفلاین (نسخهٔ کش: qadam-v3)
icon.svg       آیکون برنامه
.serve.cjs     سرور استاتیک کوچک برای پیش‌نمایش محلی
```

هیچ مرحلهٔ ساخت (build) وجود ندارد؛ فایل‌ها مستقیم در مرورگر اجرا می‌شوند.

## اجرا و پیش‌نمایش محلی

```bash
cd qadambeqadam
node .serve.cjs
# http://127.0.0.1:4173
```

می‌توانی پوشه را با هر سرور استاتیک دیگری هم باز کنی (مثلاً `npx serve .`).
باز کردن مستقیم `index.html` هم کار می‌کند، اما service worker و PWA فقط روی http فعال می‌شوند.

## انتشار روی GitHub Pages

1. در GitHub یک مخزن بساز و محتوای این پوشه را در ریشهٔ آن بگذار (`index.html` باید در ریشه باشد).
2. مخزن → Settings → Pages.
3. در Build and deployment گزینهٔ Deploy from a branch را انتخاب کن.
4. Branch: `main` و Folder: `/(root)` را بگذار و Save کن.
5. چند دقیقه بعد آدرس منتشرشده را باز کن.

برای افزودن به صفحهٔ اصلی گوشی: آدرس را در مرورگر باز کن → Share / منوی مرورگر → Add to Home Screen.
این یک وب‌اپ نصب‌شده است، نه اپ فروشگاه App Store یا Google Play.

## محدودیت‌های مهم

این پروژه یک فرانت‌اند کامل و قابل استفاده است، اما بک‌اند ندارد:

- هوش مصنوعی واقعی وصل نیست؛ پاسخ‌های دستیار نمونه و ثابت‌اند.
- حساب کاربری، پایگاه داده، همگام‌سازی و ارسال اطلاعات به سرور وجود ندارد؛ همه‌چیز در `localStorage` همان مرورگر می‌ماند.
- خروجی کارگاه یک صفحهٔ HTML ساده است: فرم فعال، پرداخت و انتشار خودکار ندارد.
- انتشار سایت کاربران، دامنه، پنل معلم و اپ بومی بخشی از این نسخه نیست.
- پاک‌کردن داده‌های مرورگر یا استفاده از حالت ناشناس، پیشرفت را از بین می‌برد.

اگر بعداً هوش مصنوعی اضافه شد، کلید API را داخل `app.js` نگذار؛ باید یک سرویس سمت سرور امن (serverless) ساخته شود.

## پیشنهاد توسعهٔ بعدی

1. سرویس امن برای دستیار هوش مصنوعی و محدودیت مصرف روزانه
2. ورود اختیاری و همگام‌سازی پیشرفت برای معلمان
3. ویرایشگر بخش‌ها و قالب‌های بیشتر در کارگاه
4. راهنمای تصویری و ویدئوی کوتاه برای هر درس
5. تست دسترس‌پذیری با کاربران واقعی، به‌ویژه کودکان و سالمندان
6. انتشار سایت کاربران با میزبانی و دامنه
